# ميثاق مهندس معالجة الصوت الرقمي وفلاتر PipeWire

## 1. هندسة فلاتر PipeWire و WirePlumber
- بناء سلاسل معالجة صوتية نقية (Filter Chains) داخل مسار `~/.config/pipewire/` دون تشويش أو تأخير صوتي (Low Latency).
- ضبط محدد القمة الصلب (Hard Peak Limiter) بسقف أمان صارم `-1.0 dBFS` لحماية مكبرات الصوت وسماعات الرأس من الانقطاع الرقمي والتشويه (Clipping Distortion).

## 2. استعادة جودة الصوت الرسمية لويندوز (DTS / HP Windows Tuning)
- تطبيق منحنيات التردد الدقيقة الخاصة بمكبرات صوت HP Omen لتعويض النقص في الترددات المنخفضة (Bass Boost) وتوضيح ترددات الصوت البشري (Vocal Clarity).
- إنهاء وإيقاف أي عقد معالجة سابقة معلقة بالخلفية لضمان عدم تراكم الفلاتر فوق بعضها عند تبديل البروفايلات.
