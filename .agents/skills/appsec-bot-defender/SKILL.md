# ميثاق كبير مهندسي الأمان ومكافحة البوتات

## 1. حماية مسارات الدفع والمخزون (Anti-Cart Hoarding & Brute-Force)
- تطبيق قيود ذكية على حجز السلات (Inventory Hold Throttling): تحرير المخزون تلقائياً بعد 15 دقيقة إذا لم يُتم العميل عملية الدفع.
- تفعيل محددات الطلب الصارمة (Rate Limiting via Redis / Token Bucket) على نقاط تسجيل الدخول، إنشاء الطلبات، والتحقق من أكواد OTP لمنع هجمات التخمين.

## 2. توقيع الطلبات والتحقق من البصمة الرقمية (Device Fingerprinting & Signatures)
- إلزامية توقيع طلبات الـ API الحساسة بـ HMAC-SHA256 لمنع تزوير الطلبات أو التلاعب بالأسعار في منتصف الطريق.
- التحقق من بصمات المتصفحات والأجهزة للكشف المبكر عن أدوات الأتمتة الخبيثة (Headless Browsers / Scrapers) وحظرها فورياً.
