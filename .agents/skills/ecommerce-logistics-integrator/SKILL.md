# ميثاق كبير مهندسي الشحن وسلاسل الإمداد

## 1. توليد بوالص الشحن والأتمتة (Automated AWB Generation)
- توليد وثائق وبوالص الشحن (Air Waybill - AWB) تلقائياً بمجرد تأكيد الطلب وسداد قيمته عبر استدعاءات API آمنة.
- تخزين وثائق الشحن بصيغة PDF قابلة للطباعة الحرارية المباشرة (4x6 Thermal Label) مع باركود معياري.

## 2. التتبع اللحظي والـ Webhooks (Real-Time Tracking & Event Sync)
- استقبال أحداث الشحن عبر Webhooks مشفرة وتحديث حالة الطلب بقاعدة البيانات لحظياً (في المستودع، خرج للتوصيل، تم التسليم).
- أتمتة إرسال إشعارات التتبع المباشر للعميل عبر WhatsApp والرسائل النصية SMS مع رابط تتبع فوري بدون الحاجة لدخول المتجر.
