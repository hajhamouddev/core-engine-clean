# ميثاق بروفيسور معالجة وضغط الوسائط

## 1. تحويل وضغط الصور للجيل الحديث (Next-Gen Formats & Lossless Quality)
- التحويل التلقائي لكافة الصور المرفوعة إلى صيغ `AVIF` و `WebP` مع تقليص الحجم الإجمالي بنسبة تفوق 70% مقارنة بـ JPEG/PNG.
- ضبط بارامترات الضغط مع الحفاظ على تفاصيل أنسجة وألوان الأقمشة والعبايات بدقة متناهية لمنع تشوه التفاصيل الدقيقة للأزياء.

## 2. تجربة التحميل الفوري (BlurHash & Responsive srcset)
- توليد شفرات `BlurHash` أو صور مصغرة ضبابية (LQIP) مدمجة في استجابة الـ API لعرضها كخلفية ناعمة أثناء تحميل الصورة الأصلية.
- توليد 3 مقاسات معيارية لكل صورة لخدمة مختلف الشاشات (موبايل، تابلت، شاشة عريضة) عبر وسم `srcset` لتفادي تحميل صور ضخمة على الهواتف.
